## How to publish on GitHub Pages

1. Sign in to GitHub.
2. Click the plus sign in the top-right corner.
3. Select **New repository**.
4. Enter this exact repository name:

   `manzunguhenry.github.io`

5. Set the repository to **Public**.
6. Tick **Add a README file** if GitHub requires it.
7. Click **Create repository**.
8. Click **Add file**, then **Upload files**.
9. Upload:
   - index.html
   - style.css
   - script.js
   - your CV PDF
   - the assets folder
10. Click **Commit changes**.
11. Open:

   `https://manzunguhenry.github.io`

Publishing may not be immediate, but GitHub normally processes the website automatically.

## Important edits before publishing

- `your-email@example.com`
- the LinkedIn placeholder link
- the CV placeholder file
- any project descriptions you want changed

## Adding project photographs

Save photos in the `assets` folder.

Example:

`assets/fogspray-road.jpg`

Then replace a project placeholder block such as:

`<div class="project-image image-road">Road Rehabilitation</div>`

with:

`<div class="project-image" style="background-image: linear-gradient(rgba(0,0,0,.2),rgba(0,0,0,.55)), url('assets/fogspray-road.jpg');">Road Rehabilitation</div>`

## Search visibility

The page currently includes:

`<meta name="robots" content="noindex, nofollow" />`

This requests that search engines do not list the website. It does not create password protection. Anyone with the link can still open it.
